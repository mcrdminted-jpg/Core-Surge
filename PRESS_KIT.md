## Game Description

### Short (1 sentence)
Core Surge is an idle tower defense game where you defend a single upgradeable tower against endless waves of enemies, building permanent power between runs.

### Medium (1 paragraph)
Core Surge combines idle mechanics with active tower defense gameplay. Players defend a central tower against waves of increasingly powerful enemies, earning coins to invest in permanent upgrades between runs. With 18 difficulty tiers, 25 collectible cards across 3 rarity tiers, 7 cosmetic skins, and competitive tournaments, Core Surge offers deep progression in quick 2-10 minute sessions. The game is free-to-play on iOS, Android, and web.

### Long (2 paragraphs)
Core Surge: Endless Tower Defense puts a fresh spin on the tower defense genre by focusing on a single tower with deep upgrade systems. Each run is a fast-paced battle where enemies approach from all sides and your tower auto-attacks while you make real-time upgrade decisions. Runs last 2-10 minutes, making Core Surge perfect for mobile play sessions. When you fall, you keep coins earned during the run and invest them in permanent stat upgrades, unlocking new ability families and powering up for the next attempt.

Beyond the core loop, Core Surge features 25 collectible cards that grant passive bonuses, 7 cosmetic tower skins with unique backgrounds, tournament leagues across 18 tiers, and milestone achievements that reward long-term dedication. The card system uses transparent odds (78% Standard, 20% Prime, 2% Apex) disclosed in-game. Built as a progressive web app wrapped with Capacitor, Core Surge delivers a native experience across iOS, Android, and desktop browsers.

## Technical Details

- **Engine:** Custom vanilla JavaScript (no framework dependencies)
- **Rendering:** DOM + Canvas hybrid
- **Native Wrapper:** Capacitor (shared codebase for iOS, Android, Web)
- **Backend:** Firebase (Auth, Firestore, Hosting)
- **Billing:** RevenueCat (cross-platform IAP)
- **Ads:** Google AdMob (rewarded, banner, interstitial)

## Monetization Model

Core Surge is free-to-play with optional in-app purchases. The game uses a fair monetization approach where all gameplay content is achievable without spending money. Premium currency (gems) accelerates progression but does not gate any content. Loot box odds are fully disclosed in compliance with Apple App Store Guideline 3.1.1 and Google Play policies.
