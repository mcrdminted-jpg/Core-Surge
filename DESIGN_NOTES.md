# Core Surge - Visual Design Notes

Based on reference mockup analysis. These notes capture the visual direction for implementation.

## Color Palette

- **Background**: Deep navy/black `#08101c`
- **Primary Accent (Cyan)**: `#00e5ff`
- **Secondary Accent (Orange/Gold)**: `#ffa726`
- **Tertiary Accent (Purple)**: `#ab47bc`
- **Health/Danger (Red)**: Used for health bars and warnings

## UI Style

- Rounded-corner panels with glowing borders
- Gradient backgrounds on cards and panels
- Dark semi-transparent overlays for modals
- Neon glow effects on interactive elements

## Navigation

- Icon-based bottom nav bar with 5 icons:
  1. Home
  2. Battle/Research
  3. Loadout
  4. Tournament
  5. More/Settings

## Top HUD (Persistent)

- Currency display: coins + gems
- Wave/best stats
- Runs counter

## Battle Screen

- Large battlefield taking 60%+ of screen height
- Tower centered in view
- Enemies approach from edges
- Concentric range circles around tower
- Upgrade grid below battlefield
- Upgrade grid uses card-based layout: icon + stat name + current/next values + cost
- Organized by tabs: Offense / Defense / Economy

## Home Screen

- Large "BEGIN DEFENSE" button (primary CTA)
- Tier selector with left/right arrows
- Daily objective panel
- Core preview display

## Research Tab

- Scrollable list of permanent upgrades
- Each entry: icon + name + level + cost
- Locked items show unlock requirement text

## Loadout Screen

- Card grid with rarity glow effects:
  - Gold border/glow = Legendary
  - Purple border/glow = Epic
  - Blue border/glow = Rare
- Equipped slots displayed at top
- Detail panel at bottom on selection

## Settings Screen

- Toggle switches with ON/OFF states
- Grouped sections: Gameplay, Account, Support, Appearance

## Skins Gallery

- Grid layout with tabs: Core / Background / UI
- Equip button per skin card

## Typography

- Bold sans-serif headings
- All-caps section titles
- Generous letter-spacing on headers
- Clean readable body text

## Important Notes

Do NOT copy exactly from references:
- Exact layout proportions
- Specific icon designs
- Specific color gradients

Use the references for direction and feel, but create our own identity.
