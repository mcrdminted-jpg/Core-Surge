## Design Notes

### Text Styling
- **Headline font:** Bold sans-serif (SF Pro Display Bold or Montserrat Bold), ALL CAPS
- **Headline size:** Approximately 5-6% of screenshot height
- **Headline color:** #FFFFFF (pure white)
- **Caption font:** Regular weight of same family
- **Caption size:** Approximately 2.5-3% of screenshot height
- **Caption color:** #FFFFFF at 90% opacity

### Overlay Background
- Semi-transparent dark overlay behind text areas
- Background color: #000000 at 50-60% opacity
- Apply to top or bottom region of screenshot (consistent across all)
- Rounded corners on overlay if positioned as a card element
- Minimum padding: 24px horizontal, 16px vertical

### Layout
- Headlines positioned at top of overlay region
- Captions positioned directly below headlines with 8px spacing
- Text horizontally centered
- Overlay region should not cover more than 25% of screenshot height
- Keep game content visible and compelling behind the overlay

### Consistency Rules
- Same font family across all screenshots
- Same overlay position (top or bottom) across all screenshots
- Same opacity and color values throughout
- Consistent padding and margins
- Headline and caption maintain same relative size ratio on all screen sizes
